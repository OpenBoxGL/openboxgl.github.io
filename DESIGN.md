# OpenBox: the collector's shelf

Second-pass art direction, following the user's request for a much more ambitious redesign. Antislop applies During. ENERGY 3 / RHYTHM 3 / MOTION 3.

## Identity and composition

The collection is the centerpiece, not a wall of feature claims. A panoramic, interactive game shelf introduces the product. A switchable viewer then shows the actual application. Source spines explain import support. An illustrated handheld demonstrates the real Big Box interface. An editorial toolkit and local-first promises supply the detail before a compact install finish.

The arrangement changes with the content: asymmetric introduction, centered cover selection, full-width image viewer, horizontal source dock, physical handheld, two-column reference notes, and centered final invitation.

## Palette and type

Charcoal stages the artwork without competing with it. Warm paper and olive distinguish the handheld and toolkit chapter. Orange comes from the existing OpenBox logo and belongs primarily to the download action. The selected cover supplies the shelf's ambient color; it is state, not an unrelated glow.

Bricolage Grotesque gives the brand a personable, collector-oriented voice. Georgia italics soften the main invitations with a printed game-manual character. Monospace is restricted to numbered selection, system readouts, and actual API syntax. Supporting prose stays sentence case.

## Purposeful motion and physical detail

- The cover shelf rotates and shifts in perspective to make the active selection legible. Hover raises an inactive case; arrows, direct clicks, and touch swipes select it. No autoplay.
- The surrounding color transitions with selection. The cover gloss and narrow spines explain physical depth. Shadows are concentrated beneath the covers and handheld.
- Source tiles lift on hover and use a paper fill to identify the selected import source.
- The handheld straightens on hover, letting the actual screen become easier to inspect.
- Product tabs swap screenshots and descriptive captions. Clicking the screenshot opens a native full-size dialog with Escape and a visible close action.
- Section entrances happen once. No looping animation, custom cursor, or scroll hijacking.
- The classic game-code interaction gives a brief, dismissing player-two message.
- Reduced motion removes transitions and entrances while retaining all content and selected states.

## Resilience and honesty

The hero is labeled an interactive preview with a sample collection. Product screenshots are actual repository assets; the handheld is explicitly illustrative. No invented popularity statistics, customer endorsements, or fake app controls. Source, view, and toolkit tabs implement keyboard selection. The shelf uses a roving tab stop plus previous/next controls. Mobile layouts reflow; the shelf's intentional cover clipping is contained within the visual stage.

The existing documentation routes and shared navigation remain intact. Feature descriptions come from repository documentation. No new application dependencies are required.
