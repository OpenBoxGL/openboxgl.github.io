title: Themes
description: Choose stock themes or import a local CSS theme.
---

Five stock Web UI themes ship with OpenBoxGL: Midnight Circuit, Phosphor Terminal, Harbor Light, Cinema Marquee, and Nordic Mist. Apply a theme globally or per platform.

Imported CSS is loaded from safe local theme paths. Preserve readable contrast in both light and dark surfaces, visible focus states, and legible controls. The public design tokens are listed in [Design system](/project/design-system/).
