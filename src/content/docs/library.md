OpenBoxGL presents imported games in a searchable grid or list. Select a card to open its detail pane, where metadata, artwork, launch, saves, and history stay together.

## Browse and search

Use platform filters, collections, favorites, playlists, status badges, and advanced search. Search terms can target fields and can exclude values. List view is useful for dense collections; grid view keeps cover browsing central.

## Organize safely

Use [Importing](/importing/), [Organizing](/organizing/), and [Queue, tags, and notifications](/queue-tags-notifications/) for focused procedures. The health audit identifies missing files, media, saves, and emulator configuration before cleanup. Duplicate-media cleanup offers a dry run before destructive changes.

Stable game identities keep sessions, queue entries, and saves attached when library order changes. Back up before bulk edits.
