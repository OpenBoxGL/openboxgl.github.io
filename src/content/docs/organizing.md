---
title: Organizing
description: Use search, filters, collections, playlists, and safe library operations.
---

Use favorites, collections, saved filters, ordered manual playlists, custom fields, ESRB filters, platform categories, and bulk edits to shape a large catalog.

Search can target fields, quoted values, status filters, and negative terms. Stable IDs keep edits and history attached to the same game. The health audit and duplicate cleanup help locate broken or redundant records before deletion.

Review the affected selection before bulk changes. Library deletion can optionally remove associated media, so keep a backup when the operation affects files.
