---
title: Getting started
description: Import one local executable and launch it safely.
---

This path is for a first run with a local executable folder. Use a disposable folder if you are testing.

1. Install and start the Web UI.
2. Choose **Import Folder**.
3. Select a folder containing one executable `.sh` file.
4. Confirm the imported title in the library.
5. Open the game card to view its details.
6. Select **PLAY** and watch the session result.

The expected result is one library entry and a completed session when the fixture exits successfully. ROMs require a configured platform emulator profile before they can launch.

If the game is missing, check the folder path and executable permission. If launch fails, open the game detail view and review its launch command or platform profile.

See [Emulators and launching](/emulators-and-launching/) for command tokens and [Interfaces and data](/interfaces-and-data/) for local state.
