---
title: Import sources
description: Configure Steam, Heroic, Lutris, Gameyfin, ROM, and arcade imports.
---

Steam imports installed libraries from standard roots. Heroic imports Epic, GOG, and Amazon manifests. Lutris imports tagged EA, Ubisoft, Xbox, and Game Pass records. Gameyfin provides a local service catalog with optional install and uninstall.

ROM and arcade workflows scan local folders by extension and can classify MAME and FinalBurn sets from DAT/XML data. Missing manifests, binaries, or malformed output are reported and skipped according to the source importer.
