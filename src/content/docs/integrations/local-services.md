---
title: Local services
description: Connect Gameyfin, OBS, MAME scores, Ludusavi, and Hoard.
---

Gameyfin uses a configured URL and credentials and reports install status through bounded polling. OBS supports native and Flatpak profile discovery and recording extensions. MAME high-score tools exchange local manifests.

Ludusavi and Hoard are optional command-line tools found on `PATH`. Their backup and restore actions affect local files and should be treated as destructive operations when restoring.
