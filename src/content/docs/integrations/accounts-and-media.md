---
title: Accounts and media
description: Configure optional metadata, achievement, artwork, and bezel services.
---

RetroAchievements, IGDB, EmuMovies, and Bezel Project integrations are optional. Credentials come from documented environment aliases and are redacted from logs and API responses. External services retain their own terms and rate limits.

Use placeholders in configuration examples and never commit credentials. Remote or archive failures should be retried only after checking the provider response and local destination.
