---
title: Importing
description: Bring storefronts, executables, ROMs, and arcade sets into one catalog.
---

Choose **Import Folder** for local executables or ROM folders. Use the dedicated Steam, Heroic, Lutris, and Arcade actions when their local manifests or DAT files are available.

OpenBoxGL also supports Gameyfin, ScummVM, RPCS3, Vita3K, loose arcade files, MAME, FinalBurn, and multi-platform folder import. Storefront imports preserve owned versus installed state where the source provides it.

Missing tools and malformed manifests are reported as import errors rather than silently creating unusable entries. Configure an emulator profile before launching ROMs.

See [Import sources](/integrations/import-sources/) for source-specific paths and [Emulators and launching](/emulators-and-launching/) for profiles.
