---
title: Queue, tags, and notifications
description: Manage the persistent play queue, normalized tags, notifications, and webhooks.
---

The Queue dialog supports enqueue, removal, ordering, notes, advance, and missing-game resolution. Queue notes are limited to 200 characters and the queue is capped at 500 entries.

Tags are canonicalized case-insensitively. The Tags dialog can filter by tag and replace selected game tags. Notifications are newest-first, deduplicated briefly, capped at 200 entries, and support read and clear actions.

Signed webhook automation is documented in [Webhooks](/integrations/webhooks/). API contracts are in [API automation](/reference/api/).
