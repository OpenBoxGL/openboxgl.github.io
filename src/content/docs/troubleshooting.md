---
title: Troubleshooting
description: Start with safe checks for startup, imports, launches, state, and integrations.
---

Start with the diagnostic log and the exact visible error. Confirm the data directory, token, executable path, and platform profile before changing state.

For startup and browser issues, verify the local server port and browser connection. For imports, check source manifests and required local binaries. For launches, check command tokens and permissions. For state recovery or backups, make a copy before destructive repair.

Security and credential problems belong in [Security and legal](/policies/security/).
