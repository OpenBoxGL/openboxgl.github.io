The application repository's `PARITY.md` is the maintenance source for capability status, acceptance checks, and Linux replacement decisions. This page is the single rendered status authority.

OpenBoxGL targets mixed-library management, imports, metadata, launch profiles, Big Box, sessions, saves, integrations, plugins, and local automation. Windows-only workflows without a Linux equivalent remain documented as boundaries rather than implied support.

See the [source parity matrix](https://github.com/vindeckyy/OpenBoxGL/blob/master/PARITY.md) for the current row-level evidence.
