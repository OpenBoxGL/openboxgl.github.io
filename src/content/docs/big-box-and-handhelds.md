---
title: Big Box and handhelds
description: Browse a library fullscreen with controller-oriented layouts.
---

Big Box provides Stage, Hybrid, and CoverFlow layouts, gamepad navigation, fullscreen search, filter and sort menus, themes, screensaver and attract behavior, optional startup video, and background music.

Steam Deck and similar gamescope sessions can open Big Box with `--game-mode`. Steam keeps its Input and Quick Access Menu controls while OpenBoxGL runs as a gamescope guest. Do not nest another gamescope session inside that guest.

See [Handheld performance](/handheld-performance/) for the TDP profile behavior supported by the current release.
